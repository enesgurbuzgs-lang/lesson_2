# Домашнее задание 2: линейная и логистическая регрессия

1. **Модификация моделей.** На Diabetes сравниваются обычная линейная регрессия, L1, L2 и L1 + L2. Ранняя остановка следит за ошибкой на валидации и восстанавливает лучшие веса. На Iris обучается логистическая регрессия для трёх классов. Выводятся macro precision, recall, F1 и ROC-AUC (one-vs-rest), сохраняется матрица ошибок.
2. **CSV Dataset.** Diabetes (регрессия) и Wisconsin Diagnostic Breast Cancer (бинарная классификация) взяты из встроенных наборов scikit-learn и экспортированы в CSV. CSVDataset преобразует числовые, бинарные и категориальные признаки в тензоры. Числовые признаки стандартизируются, строковые категории кодируются one-hot. Преобразования обучаются только на тренировочной части.
3. **Эксперименты.** Проверяются 27 сочетаний скорости обучения, размера батча и оптимизатора (SGD, Adam, RMSprop). По валидационной MSE выбираются параметры. Базовые признаки сравниваются с полиномиальными признаками второй степени, попарными взаимодействиями, средним и дисперсией строки на одной тестовой выборке.

Во всех задачах используется разбиение 60/20/20 с seed=42. При классификации сохраняются пропорции классов. MSE на тесте выражена в исходной шкале целевой переменной.

## Запуск

Из корня репозитория с Python, в котором установлены PyTorch, scikit-learn и matplotlib:

```powershell
python homework/homework_model_modification.py
python homework/homework_datasets.py
python homework/homework_experiments.py
python -m unittest discover -s homework -v
```

Результаты сохраняются в `homework/plots/`, модели и параметры предобработки — в `homework/models/`, исходные CSV — в `homework/data/`. Ход обучения и метрики выводятся в терминал через logging.
